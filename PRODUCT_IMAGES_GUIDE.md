# Product Images Feature Guide

The AI Blog Generator now supports including small product images (max 250px wide) that link directly to products when referenced in blog content.

## Setup Instructions

In your products context, include this format for each product:

```
Product Name: [Product Name]
Description: [Product Description]
Image URL: [Direct URL to product image]
Product URL: [Link to product page]
---
```

## Features

- Automatic product image inclusion when products are referenced
- Clickable images that link to product pages
- Responsive design with hover effects
- Multiple display styles (inline, showcase, basic link)
- 250px maximum width constraint
- SEO-optimized with proper alt text

## CSS Classes

- `.product-image` - Basic product images
- `.product-link` - Clickable containers
- `.product-showcase` - Featured displays
- `.inline-product-image` - Inline floating images

The AI will automatically generate appropriate HTML when referencing products from your context.
